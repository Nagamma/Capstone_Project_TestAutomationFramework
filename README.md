# Retail Enterprise ETL Test Automation Framework

A Python-based ETL Test Automation Framework designed for validating retail enterprise data pipelines across Extraction, Transformation, and Loading (ETL) stages. The framework automates source-to-target data validation by comparing source files (JSON, XML, CSV) with staging and warehouse database tables to ensure data accuracy, completeness, and integrity.

Built using **Python, Pytest, Pandas, SQLAlchemy, and MySQL**, the framework supports automated data reconciliation, schema validation, row count verification, null checks, duplicate checks, and business rule validations. It also includes modular logging, reusable fixtures, database utilities, and structured reporting for scalable and maintainable ETL testing.
